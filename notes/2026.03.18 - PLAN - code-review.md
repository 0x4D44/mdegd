# Code Review Plan — mdegd (Eric's Birthday Quiz)

## Scope
All source code, tests, configuration, and HTML in the repository.

## Files Under Review

| File | Lines | Role |
|------|-------|------|
| `index.html` | 676 | SPA entry point — inline CSS, inline JS, DOM orchestration |
| `src/quiz-engine.js` | 144 | Pure logic — shuffle, select, answer check, scoring, messages |
| `src/styles.js` | 643 | 10 CSS themes with variables and extraCSS injection |

**Total:** ~10,400 lines

## Review Dimensions

### 1. Correctness & Logic
- [ ] `shuffleArray` — Fisher-Yates correctness
- [ ] `selectQuestions` — no duplicates, bounds handling
- [ ] `selectBalancedQuestions` — round-robin correctness, termination guarantee
- [ ] `checkAnswer` — text-matching logic for duplicate options (Ruth mode)
- [ ] `calculateScore` — division-by-zero handling
- [ ] `getResultMessage` — boundary conditions for percentage thresholds
- [ ] `isBirthday` — date logic correctness
- [ ] Option shuffling in `showQuestion` — does it preserve correct answer tracking?
- [ ] Ruth mode always scoring 12/12 — is this watertight?
- [ ] Hidden card bonus — does it carry through to display correctly?
- [ ] `CATEGORY_LABELS` — sync with actual categories in questions.js

### 2. Security
